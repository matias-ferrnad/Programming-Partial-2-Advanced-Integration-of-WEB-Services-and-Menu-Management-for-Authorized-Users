# Integración de Servicios WEB y Gestión de Menús para Usuarios Autorizados
Este proyecto se centró en tareas clave: Crear un Servicio Web (WS) para la Visualización de Menús. Desarrollar una Página Web de Promociones utilizando el WS para Mostrar Ofertas. Implementar un Servicio Web de Gestión de Menús (Adición, Eliminación, Modificación, Listado), limitado a Usuarios Válidos (Oficiales en la Base de Datos).
